# ניהול תקציב – הוראות התקנה

יש שתי גרסאות מאותו קוד. בשתיהן הנתונים נשמרים במכשיר בלבד, בלי שרת ובלי חשבון.

## גרסת מחשב: maatafot.html

- פותחים את הקובץ בלחיצה כפולה. עובד גם בלי אינטרנט.
- הנתונים נשמרים בדפדפן שבו נפתח הקובץ. פותחים תמיד באותו דפדפן, ולא מעבירים את הקובץ לתיקייה אחרת.
- פעם בחודש: הגדרות ← שמירת גיבוי.

## גרסת אייפון: העלאה ל-GitHub Pages (חינם)

האתר רק מגיש את הקוד לטלפון. הנתונים לא עוברים אליו ונשארים בטלפון.

1. נכנסים ל-github.com ופותחים חשבון (אם אין).
2. יוצרים Repository חדש בשם `maatafot`, מסוג Public.
3. בתוך ה-Repository: **Add file ← Upload files**. גוררים את **התוכן** של תיקיית `maatafot-pwa` (כל הקבצים, בלי תיקיות), לא את התיקייה עצמה. לוחצים **Commit changes**.
4. **Settings ← Pages**. תחת Source בוחרים **Deploy from a branch**, ענף `main`, תיקייה `/ (root)`, ולוחצים **Save**.
5. אחרי דקה-שתיים הכתובת תופיע למעלה, בצורה `https://שם-המשתמש.github.io/maatafot/`.

### התקנה באייפון

1. פותחים את הכתובת **בספארי**.
2. כפתור השיתוף ← **הוסף למסך הבית** ← הוסף.
3. מעכשיו פותחים רק מהאייקון. הנתונים בספארי ובאייקון נפרדים.

### התקנה באנדרואיד

1. פותחים את הכתובת **בכרום**.
2. תפריט (שלוש הנקודות) ← **הוספה למסך הבית** או **התקנת אפליקציה**.

## עדכון גרסה

1. מעלים את `index.html` החדש במקום הישן.
2. ב-`sw.js` משנים את השורה `const CACHE = "maatafot-v24";` למספר הבא (`v25`, `v26`...).
3. הטלפונים יקבלו את העדכון בפתיחה הבאה עם אינטרנט. הנתונים לא נפגעים.

## מעבר בין מכשירים

במכשיר הישן: הגדרות ← שמירת גיבוי. במכשיר החדש: הגדרות ← שחזור מגיבוי.
