העלאה ל-GitHub Pages

חינם. האתר רק מגיש את הקוד לטלפון, והנתונים לא עוברים אליו.

  1. פותחים חשבון ב-github.com (אם אין).
  2. יוצרים Repository חדש בשם maatafot, מסוג Public, בלי לסמן תיבות נוספות.
  3. בתוך ה-Repository: Add file ← Upload files. בוחרים את כל הקבצים שבתוך התיקייה maatafot-pwa, לא את התיקייה עצמה, ולוחצים Commit changes.
  4. Settings ← Pages. תחת Source בוחרים Deploy from a branch, ענף main, תיקייה / (root), ולוחצים Save.
  5. אחרי דקה-שתיים מופיעה למעלה כתובת האתר:https://USERNAME.github.io/maatafot/
בטלפון, אם כפתור לא מופיע ב-GitHub, בוחרים בדפדפן אתר למחשב שולחני ואז כל הכפתורים מוצגים.

בדיקה על אייפון לפני מסירה

עוברים על הרשימה במכשיר האמיתי של המשתמש. כל סעיף לוקח פחות מדקה.

  1. התקנה: הכתובת נפתחת בספארי, "הוסף למסך הבית" עובד, והאייקון והשם "ניהול תקציב" נראים נכון.
  2. מסך מלא: באפליקציה המותקנת אין שורת כתובת, והתוכן לא מוסתר מאחורי הנוץ' או הפס התחתון.
  3. הקמה: ארבעת המסכים עוברים, המקלדת המספרית נפתחת בשדות הסכום, ואין זום אוטומטי כשמקלידים.
  4. הוצאה: כפתור + פותח את החלון, ההשלמה האוטומטית של שמות עובדת, ובורר התאריך נפתח.
  5. קבועות: העיגול מסמן "שולם", וכפתור הביטול בהודעה עובד.
  6. חובות: הלוואה שנוספה מופיעה בקבועות, וסימון "שולם" מוריד את היתרה.
  7. גיבוי: "שמירת גיבוי" פותח את תפריט השיתוף, והקובץ נשמר ב"קבצים".
  8. שחזור: "שחזור מגיבוי" פותח את בורר הקבצים ומחזיר את הנתונים.
  9. יומן: שתי התזכורות, שבועית וחודשית, נפתחות כאירוע עם כפתור "הוסף ללוח השנה".
  10. נעילה: הפעלת קוד, יציאה מהאפליקציה לדקה וחזרה: מסך הקוד מופיע.
  11. אופליין: במצב טיסה האפליקציה נפתחת מהאייקון עם כל הנתונים.
  12. מדריך: בהגדרות ← איך משתמשים? ← "המדריך המלא" נפתח ה-PDF.
